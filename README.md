# Estúdio Nova Era - Micropigmentação & Estética

Landing page profissional para o **Estúdio Nova Era**, especializado em micropigmentação de sobrancelhas, lábios e estética facial localizado em Osasco - SP.

## 🚀 Tecnologias Utilizadas

- **HTML5 & CSS3**
- **Tailwind CSS** (via CDN)
- **Google Fonts** (*Cormorant Garamond* & *Plus Jakarta Sans*)
- **FontAwesome 6**
- **Schema.org (JSON-LD)** para SEO Local e Google Meu Negócio

## 🌐 Deploy Automático (Vercel)

Este repositório está integrado à Vercel. Qualquer commit enviado para a branch `main` gera uma nova versão em produção automaticamente.
